
## Цель

Из 14 макетов на `/mockups` (экраны 1 → 13, плюс 8b) собрать связный интерактивный прототип мобильного приложения. Живёт на `/app/*`, реализован как обычная React-вёрстка без рамки телефона (мобильный layout, на десктопе центрируется max-width ~420px). Лендинг на `/` не трогаем. Все данные моковые, платежи — только UI.

## Маршруты

```text
/app                   → 1. Splash (авто-редирект через 1.5с на /app/home)
/app/home              → 2. Главная (промо, вход, поиск, флаги 8 стран, «Все страны»)
/app/countries         → 3. Все страны (полный каталог с «от … ₽»)
/app/country/:slug     → 4. Тарифы страны (пакеты 1/3/5/10/20 ГБ)
/app/checkout/:slug/:planId → 5. Оформление / оплата (карта/СБП/крипто)
/app/install/:orderId  → 6. Установка eSIM (шаги + ссылка в поддержку)
/app/my-esim           → 7. Мой eSIM (активный пакет, прогресс, «Добавить пакет»)
/app/profile           → 8. Профиль (залогинен, история покупок)
                         8b. Профиль пустой (не залогинен) — тот же роут, ветка по auth
/app/login             → 9. Вход (email)
/app/login/code        → 10. Код подтверждения (4 цифры, таймер 00:45)
/app/register          → 11. Регистрация (email)
/app/support           → 12. Поддержка (FAQ + вход в чат)
/app/support/chat      → 13. Чат с агентом
```

Нижний таб-бар (Главная / Мой eSIM / Профиль) виден на экранах 2, 3, 7, 8, 8b — как на макетах.

## Архитектура

- Новый layout `src/app/AppLayout.tsx` — обёртка `min-h-screen` + центрированный `max-w-[420px]`, единый top-bar/статус-бар из макетов, опциональный `BottomTabBar`.
- Компоненты в `src/app/components/`: `StatusBar`, `TopBar`, `BottomTabBar`, `CountryCard`, `PlanCard`, `PaymentMethodRow`, `ChatBubble`, `OTPInput`, `TravelProgress`, `PromoCard`, и т.д. — по одному на повторяющийся паттерн из макетов.
- Стили — существующие семантические токены из `index.css` (индиго/фиолетовый как в макетах). Никаких хардкодных цветов.
- Мок-стор в `src/app/store.ts` — Zustand или React Context + `localStorage`:
  - `auth`: `null | { email }`
  - `orders`: массив «купленных» пакетов (страна, объём, дни, дата, цена)
  - `activeEsim`: текущий пакет + израсходованные ГБ
  - `chatMessages`: массив предзаписанных реплик
- Данные стран/тарифов — расширенная версия текущих `src/data/heroCountries.ts` (добавить полный каталог для экрана 3).
- Мок-чат: пользовательские сообщения добавляются реально; ответ агента приходит с задержкой 800 мс из предзаписанного скрипта.
- OTP: любые 4 цифры засчитываются как валидный код, залогинивают под введённым email.

## Связки между экранами

- Splash: `setTimeout` → `/app/home`.
- Главная: тап по флагу → `/app/country/:slug`; «Все страны →» → `/app/countries`; строка входа → `/app/login`; промо «Попробовать бесплатно» → `/app/country/promo` (тариф 1 ГБ бесплатно).
- Страна: тап по пакету → `/app/checkout/:slug/:planId`.
- Оплата: `Оплатить` → создаём mock-order в сторе → `/app/install/:orderId`.
- Установка: `Готово` → `/app/my-esim`; ссылка в поддержку → `/app/support/chat`.
- Мой eSIM: `Добавить пакет` → `/app/countries`.
- Профиль: если `auth === null` → рендер 8b (пустой профиль с login row); иначе 8 (email + история из `orders`). «Войти» → `/app/login`.
- Вход: `Продолжить` → `/app/login/code` (передаём email). «Зарегистрироваться» → `/app/register`.
- Код: 4 цифры → `setAuth(email)` → `/app/my-esim`. «Отправить снова» активно после 00:45.
- Регистрация: `Продолжить` → `/app/login/code`.
- Поддержка: `Написать в чат` → `/app/support/chat`.

## Что НЕ делаем

- Не трогаем `/`, `/legal`, `/login` (текущая beta-заглушка), `/mockups`.
- Не подключаем Lovable Cloud, не делаем реальную авторизацию, БД или платежи.
- Не меняем существующий i18n лендинга; экраны приложения — на русском, как на макетах.
