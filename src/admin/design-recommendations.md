# For approval — revised design recommendations

- Keep a permanently visible **Reset** control between the new price and margin. One action resets both manual overrides to the pricing rule without shifting the plan block.
- Recommend changing the currently purple bulk **Publish** controls to green, matching individual plan publication. This is a recommendation, not an implemented color change.
- Match the existing compact table: 12 px body text, 10 px secondary text and headings, 32 px price/margin fields and row Publish controls, and 28 × 16 px network toggles.
- Keep each plan and its network costs/toggles as one visual block, with selection highlighting the whole block and stable field dimensions.
- Keep inline manual price and percentage-margin editing without number steppers; show monetary margin below the percentage.
- Preserve country grouping, Expand all / Collapse all, separate alphabet and data-volume filters, and search immediately above the table. Do not restore removed notices, Check, Warnings only, or Recently viewed in this tab.
- Retain actual supplier package durations; do not impose a uniform duration based on demo examples. Verify 7-, 14-, and 30-day plans against supplier input.
- Keep **Publish** available despite pricing warnings or disabled networks. Warnings may remain advisory; malformed/non-positive price input reports an error on application rather than disabling Publish. Bulk publication requires a selected plan.
- Keep the interface in English and clearly identify publication as a session-only demonstration.

The earlier corrections about repeated country names, country-header plan counts, and the transition-to-euro discrepancy have been removed. The standing requirement that tariff sale prices are in EUR is unchanged; no currency migration is part of this update.
